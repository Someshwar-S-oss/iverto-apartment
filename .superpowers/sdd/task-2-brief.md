## Requirements
1. **Receipt PDF Streaming in `BillingReportsService`**:
   - In `backend/src/modules/billing/billing-reports.service.ts`, implement:
     `async streamInvoiceReceiptPdf(societyId: string, invoiceId: string, outStream: NodeJS.WritableStream): Promise<void>`
   - Query the invoice details using `InvoicesService.getDetail(societyId, invoiceId)` (which already has line items and enriched payments from Task 1).
   - Also fetch the society details (name, address) from `societies`, and unit & building details (`units.unitNumber`, `buildings.name`) from `units` / `buildings`.
   - Use `PDFDocument` (from `pdfkit`, which is already installed and imported in `billing-reports.service.ts`) to stream a clean, professional, publication-quality A4 receipt/tax invoice:
     - Header:
       - Society Name (bold, 18pt), Society Address, "OFFICIAL MAINTENANCE BILL & PAYMENT RECEIPT".
       - Generation Date / Print Date.
     - Invoice & Unit Details Block (2-column layout or structured box):
       - Invoice Number (e.g. `INV-2026-09-0001`)
       - Billing Period (e.g. `2026-09`)
       - Due Date
       - Unit / Flat: Building Name - Unit Number
       - Status badge text: `PAID`, `PARTIALLY PAID`, `OVERDUE`, or `PENDING`
     - Itemized Charges Table:
       - Table header: Description, Category, Amount (₹)
       - Rows for each `lineItem`: Description, Category, Amount formatted with ₹
       - Total Amount line
     - Payment History Section (if `invoice.payments.length > 0`):
       - For each payment: Date (`paidAt` or `createdAt`), Method (`RAZORPAY`, `MANUAL`, `OFFLINE`), Reference/Txn ID, Payer (`paidByName` & `paidByRole`), Amount Paid (₹)
     - Financial Summary Box:
       - Total Invoiced: ₹...
       - Total Amount Paid: ₹...
       - Outstanding Balance: ₹...
     - Footer:
       - Note: "This is a computer-generated receipt/invoice for society maintenance dues. Generated by Iverto Apartment Management."
   - Pipe the PDF document to `outStream`.

2. **Mobile/Resident Controller Endpoint**:
   - In `backend/src/controllers/mobile/mobile-billing.controller.ts`:
     - Inject `BillingReportsService` into `MobileBillingController`.
     - Ensure `BillingModule` exports `BillingReportsService` and provides it properly.
     - Add route:
       ```typescript
       @Get('invoices/:id/receipt')
       @RequirePermission('billing.view', ScopeType.UNIT)
       async getInvoiceReceipt(
         @Param('unitId') unitId: string,
         @Param('id') id: string,
         @Res() res: Response,
       ) {
         const societyId = await this.resolveSocietyId(unitId);
         const invoice = await this.invoicesService.getDetail(societyId, id);
         if (invoice.unitId !== unitId) {
           throw new NotFoundException(`Invoice ${id} not found for this unit`);
         }
         res.setHeader('Content-Type', 'application/pdf');
         res.setHeader('Content-Disposition', `inline; filename="receipt-${invoice.invoiceNumber}.pdf"`);
         await this.billingReportsService.streamInvoiceReceiptPdf(societyId, id, res);
       }
       ```
